# 🍕 Pizza Sales Analysis using SQL & Power BI

## 📌 Project Overview
This project focuses on analyzing **pizza sales data** using **MS SQL Server** and visualizing insights through an **interactive Power BI dashboard**.  
SQL queries were used to calculate **business KPIs**, analyze **sales trends**, and identify **top & bottom performing pizzas**, while Power BI was used to transform these insights into clear visual reports.

---

## 🛠️ Tools & Technologies Used
- **MS SQL Server** – Data storage and query execution  
- **SQL** – Data analysis and KPI calculations  
- **Power BI** – Data visualization & dashboard creation  
- **Power BI – SQL Server Connector** – Live data connection  

---

## 🗂️ Dataset Description
The analysis is performed on a table named:

### Key Columns:
- `order_id` – Unique order identifier  
- `order_date` – Order date  
- `pizza_name` – Name of the pizza  
- `pizza_category` – Pizza category (Classic, Veggie, etc.)  
- `pizza_size` – Pizza size (S, M, L, XL)  
- `quantity` – Number of pizzas sold  
- `total_price` – Total order price  

---

## 🔷 Key Performance Indicators (KPIs)

KPIs are placed at the **top of the dashboard** using individual cards for quick visibility.
